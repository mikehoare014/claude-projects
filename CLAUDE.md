# Claude Project Prompt Repo

This repo stores markdown files used as project instructions in the Claude app (claude.ai). The purpose of this repo is to develop and maintain those instruction files using Claude Code.

## What's here

- Markdown files containing system prompts and instructions for various Claude projects
- Each file is a standalone set of instructions used in a specific Claude app project

## Working in this repo

The task here is authoring and refining markdown — not running code. Changes are committed and synced so the latest instructions are always tracked in git.
